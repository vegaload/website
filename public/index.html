Pass or fail gates

Set limits for p95 latency, error rate, and checks. A broken limit exits 3. It stops the pull request in CI, or the rollout in CD.

Baseline comparison

Save a good run. Later runs automatically detect latency or error rate regressions.

Results where your pipeline looks

JUnit XML for your CI or CD system. A rich job summary on the GitHub Actions page.

Start from what you have

Build a scenario from an OpenAPI spec or a browser HAR recording with auto-correlation.

Single static binary

Zero JVM, zero Node runtime. Native on macOS, Linux, Windows, Docker, and Kubernetes.

Safety Guardrails

Your agent can only test hosts you approve.

Localhost is always allowed. Any other target host needs your approval. Every run is written to an audit log on your machine, with strict caps on concurrency and duration.

Host allow-list Audit log (~/.vegaload) RPS & duration caps
  • $vegaload run -target https://staging.example.com/health -protocol http1
  • Target "https://staging.example.com/health" is not localhost or allowlisted. Continue? [y/N]
  • vegaload run: refusing to run against "https://staging.example.com/health" without confirmation (pass -yes, or add it with -allow-target)
  • ~/.vegaload/audit.log, one line per run
  • {"trigger":"mcp","scenario":"checkout.load.js","vus":10,"outcome":"success"}
